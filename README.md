# 紬 / 7day-mvp

40〜60代の女性向け投資教育講座の需要を、無料相談の申込で検証するMVP。日本語・レスポンシブの講座紹介、申込フォーム、SQLite保存、認証付き管理者一覧を備えています。

## 開発・起動

Node.js 24以上を使用します（Node標準のSQLiteを使用。実験的機能の警告が出る場合があります）。外部依存パッケージやインストール作業は不要です。

```sh
cd /workspace/7day-mvp
# 秘密値は環境設定で注入。ローカルの場合は端末で設定します。
export ADMIN_PASSWORD='十分に長いランダムなパスワードに置き換える'
npm start
```

公開ページは `/`、管理者一覧は `/admin`。ブラウザのBasic認証ではユーザー名に `admin`、パスワードに `ADMIN_PASSWORD` を入力します（パスワードで認証）。未設定時は管理者画面・APIとも503で閉じます。フォームはパスワード未設定でも利用可能です。`.env` を使う場合は `node --env-file=.env server.js` で起動してください。`.env.example` は項目の見本です。

```sh
npm test
```

HTTP経由のテストで日本語ページ、正常申込、不正入力、同意必須、別オリジン拒否、認証、不正パスワード、未設定時の拒否、再起動後の永続化、送信制限を確認します。テストデータは一時ディレクトリに作成し削除します。

## 保存と運用

- `data/app.sqlite` に申込を保存します。DB・個人情報・秘密値はGit対象外です。サーバー再起動後も保持されますが、使い捨てディスクのホスティングでは消えます。単一インスタンス＋永続ディスクを使用してください。
- 管理者一覧は新しい順に最大500件。氏名・メール・希望時間帯・相談内容・日本時間の受付日時を表示します。相談内容はHTMLとして解釈しません。
- 管理画面は個人情報を扱うため、公開はHTTPS必須です。リバースプロキシを前段に配置し `NODE_ENV=production` を指定、HostとOriginのホスト名を維持してください。可能なら管理画面にアクセス制限も設定します。Basic認証をHTTPで公開しないでください。
- 送信は接続元IPごとに1時間10件まで。プロセス再起動でリセットされ、リバースプロキシ配下では同一IPとして数えられます。公開運用ではプロキシ側の制限を合わせて調整してください。
- 自動メール・日程確定・決済は未実装です。毎日管理者一覧を確認し、2営業日以内に手動でメール連絡してください。管理者への通知も自動送信されません。
- 対応終了から90日を目安に削除する運用です。現状はDBを管理する運用者が対象レコードを確認して削除します（自動削除・管理画面の削除機能は未実装）。バックアップも個人情報として管理し、削除方針を適用してください。
- SQLiteファイルを稼働中に単純コピーせず、SQLiteのバックアップ機能等を利用して保全してください。複数プロセスや大量アクセスを前提にした構成ではありません。

## 公開前に確定すること

1. 運営者名・問い合わせメール・個人情報の管理責任者を決め、紹介ページの個人情報説明に掲示する。
2. ブランド「紬」、全3回・各60分の講座案、受講料、開催日、講師情報を確定する。現状は準備中と明示し、収益・実績の仮情報は載せていません。
3. `ADMIN_PASSWORD`、公開ドメイン、HTTPS、永続ディスク、バックアップ、削除担当を設定する。
4. 日程調整用の送信元メールとオンライン相談ツールを準備し、実際のメール到達と相談接続を確認する。
5. 有料講座販売を始める際は利用規約・キャンセル条件・特定商取引法に基づく表示等を整備する。このMVPでは決済を行いません。

## 7日間の検証案

- 1日目：上記公開設定を完了し、スマートフォンでフォーム送信から管理者確認、手動メールまでを通しで確認。
- 2〜5日目：対象者にページを案内。配布先ごとの案内数・訪問数（別途計測）・申込数を記録し、無料相談で悩みと受講意思をヒアリング。
- 6日目：相談で実際の予定価格を示し、価格への反応と参加希望を記録。
- 7日目：申込件数・相談実施数・価格提示後の受講希望数で継続判断。仮の目標は「対象者100訪問、申込5件、相談3件、受講希望1件」。訪問解析は未搭載なので別途集計する。

無料相談申込だけでは有料販売の成立は検証できません。受講希望は購入確約と区別し、正式販売時に検証してください。
